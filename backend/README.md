# HNG Backend Repository

This repository contains tasks for the HNG Backend internship program.

## Projects

### Stage 0 - Gender Classification API

Located in `hng-stage0-api/`

A REST API that predicts gender from a given name using the Genderize.io API.

- **Live URL**: https://hng-backend.up.railway.app
- **Endpoint**: `/api/classify?name=Name`

See `hng-stage0-api/README.md` for detailed documentation.

## Getting Started

```bash
cd hng-stage0-api
npm install
node index.js
```

Server runs on http://localhost:3000
